# Padrão de Desenvolvimento

## Objetivo

Manter o projeto organizado, simples e fácil de manter.

---

## HTML

- Utilizar comentários para separar seções.
- Utilizar nomes consistentes.
- Evitar código duplicado.

---

## CSS

- Base
- Componentes
- Páginas
- Responsivo

---

## JavaScript

- Uma função para cada responsabilidade.
- Código organizado por seções.

---

↓
